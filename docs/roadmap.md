# Roadmap

SDEA is built in controlled increments. Stable contracts come before broad integrations.

## M0 — Foundation
- Repository architecture
- Canonical domain contracts
- Invariants
- Testing strategy
- Documentation and ADR discipline
- CI and security baseline

## M1 — Signal foundation
- Source adapters
- Normalization
- Deduplication
- Source reliability metadata
- Provenance references

## M2 — Evidence and fusion
- Evidence graph
- Correlation
- Signal clustering
- Contradiction handling
- Temporal reasoning

## M3 — Demand and capability inference
- Demand hypotheses
- Capability ontology
- Capability inference
- Confidence calibration
- Explainability

## M4 — Opportunity intelligence
- Opportunity graph
- Buying windows
- Opportunity decay
- Qualification
- Acquisition-mode recommendations

## M5 — Integrations
- TADS
- ReconOS
- FadeReach
- FDSE/FDE
- Domain adapters

## M6 — Evaluation and enterprise hardening
- Benchmark suite
- Precision/recall and calibration
- Auditability
- Policy controls
- Observability
- Cost controls
- Multi-tenant boundaries where required

Each milestone must leave the repository testable and documented.

# Support

## Before asking for help

Check the [README](README.md), [documentation index](docs/README.md), [deployment runbook](deploy/README.md), and existing GitHub issues.

## Questions and troubleshooting

For reproducible bugs, use the bug-report issue form.

For feature proposals, use the feature-request form and explain the problem, affected boundary and expected outcome.

For private operational or commercial questions, contact **hello@tinlance.com**.

## Security

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
